# Cut abilities and prototype leaders

## Card abilities that exist only as names

The Gwent screen defines a list of card abilities. Six of them have a name and nothing else: no
rule, no card, no tooltip, no text. A seventh exists only in the deck strength calculation.

| Ability | What the name suggests | What is left |
|---|---|---|
| Backstab | An attack from behind | Only the name |
| Ambush | A surprise play | Only the name |
| Tough Skin | A sturdier unit | Only the name |
| Morale boost (a second one) | Another kind of Morale, next to the Morale and Tight Bond of the final game | Only the name |
| Discard two | Throw away two cards | Only the name (an early Monsters leader used it, see below) |
| Discard three | Throw away three cards | Only the name |
| Draw one | Draw a single card | Counted in the deck strength measure, but no card has it and it does nothing in a match |

None of them reached the interface: the game's tooltips cover only the abilities in use.

## An early set of leaders

An older leader file keeps **16 prototype leaders**, all disabled and all pointing to a placeholder
picture of King Henselt that does not exist in the game. They show an earlier stage of the design:

| Prototype faction | Ability | Became, in the final game |
|---|---|---|
| Northern Realms | Clear the weather | Foltest (bronze) |
| Northern Realms | Pull Impenetrable Fog from the deck | Foltest (copper) |
| Northern Realms | Horn on the siege row | Foltest (silver) |
| Northern Realms | Scorch the enemy siege row | Foltest (gold) |
| Scoia'tael | Pull Biting Frost from the deck | Francesca (copper) |
| Scoia'tael | Horn on the ranged row | Francesca (silver) |
| Nilfgaard | An eleventh card at the start | Francesca (bronze), Scoia'tael |
| Nilfgaard | Pull Torrential Rain from the deck | Emhyr (copper) |
| Nilfgaard | Look at three enemy cards | Emhyr (bronze) |
| Nilfgaard | Revive a card from the enemy's discard pile | Emhyr (gold) |
| Nilfgaard | Discard two, then pick one from the deck | Eredin (gold), Monsters |
| Nilfgaard | Cancel the enemy leader | Emhyr (silver) |
| Monsters | **Discard two** | **Nothing: cut** |
| Monsters | Pull any weather from the deck | Eredin (bronze) |
| Monsters | Revive a card from your discard pile | Eredin (silver) |
| Monsters | Horn on the melee row | Eredin (copper) |

So the abilities moved between factions before release (the eleventh card went from Nilfgaard to
Scoia'tael, "discard two, pick one" from Nilfgaard to Monsters), and one Monsters leader ability
was dropped.
