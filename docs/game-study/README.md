# Studying the game: what I found

While building Better Gwent I read the game's own Gwent data closely: the card and deck
definitions, the Gwent screens, the scripts and the texture list. Along the way I found cut
content, unused art, abandoned features and a few bugs of the base game.

These pages describe what I found **in plain words**. They never reproduce the game's code,
data or texts; the only images are the game's own **unused** art, shown as previews (see
[Repository scope](../PUBLICATION_SCOPE.md)). Everything was found by reading the game's files;
nothing in the game was changed to study it.
