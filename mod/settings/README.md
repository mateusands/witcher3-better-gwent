# Better Gwent settings sources

Sources for **Options > Mods > Better Gwent** and the game-side scripts:

- `menu/modGwentAI.xml`: main switch, difficulty, NPC decks, player AI, common wager maximum
  and stakes-dependent NPC strength.
- `menu/labels.en.json`: English menu text; `menu/labels.translations.json`: the other 17
  languages (a missing text stays in English). `tools/build_settings.py` compiles them.
- `modGwentAISettings/content/scripts/local/gwai_settings.ws`: defaults, persistence, locking
  of the sub-options while the mod is Off, and the per-match settings sent to the Gwent board.
- `modGwentAISettings/content/scripts/local/gwai_betting.ws`: the repaired NPC deck
  requirements (`GetDifficulty`), the common pure-gold wager maximum and the stronger stakes.
- `modGwentAISettings/content/scripts/local/gwai_npc_decks.ws`: the NPC deck option; its
  table `gwai_npc_decks_data.ws` is generated by `tools/build_npc_decks.py` and not committed.

Difficulty values: 0 = Easy, 1 = Normal, **2 = Hard (default)**; a saved 3 (Expert, before 0.9.0)
plays as Hard. Missing or invalid
switches fall back to Off. Turning the main switch Off locks every sub-option (wagers included)
and keeps their saved choices; the game then behaves as shipped. Player AI is effective only
when the main switch and the player-AI switch are both On. The native difficulty preference is
never changed.

With Better Gwent On, every NPC extra-card requirement is rebuilt from the mod's difficulty
(the vanilla `GetDifficulty` check is repaired for all 15 levels). Special 50/100 wagers and
quest rewards stay vanilla; only the common money wager gets the higher maximum.

The scripts wrap existing methods with annotations; they are original mod additions and no
game resources are in this folder. Tests: `sim/tests/test_options.py`,
`sim/tests/test_difficulty_dispatch.py`, `sim/tests/test_npc_deck_table.py`.
